# 🛒 E-Commerce Website
### Project Planning & Management

> A structured project management plan for developing a modern E-Commerce Website using Microsoft Project.

---

## 📌 Project Overview

The **E-Commerce Website Project** is a planned web-based shopping platform designed to provide customers with a simple, secure, and convenient online shopping experience.

This repository focuses on the **planning and management of the project**, including project scheduling, task dependencies, project calendar, milestones, resource allocation, Gantt Chart, and Network Diagram.

The complete project lifecycle is planned using **Microsoft Project**.

---

## 🎯 Project Objectives

- Plan and schedule the complete project lifecycle.
- Define project activities and task dependencies.
- Establish a customized project working calendar.
- Estimate task durations and project timeline.
- Identify important project milestones.
- Manage project resources effectively.
- Create Gantt Chart and Network Diagram.
- Monitor project progress and completion.
